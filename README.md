Linux Dashboard is a desktop app that lets you do everyday Linux tasks with buttons, switches and sliders instead of typing terminal commands.

It covers settings like display, sound, Wi-Fi, power and the desktop's look. It installs and updates apps, and shows running programs, services, storage, temperatures, logs and virtual machines. It also has a toolbox of one-click fixes and handy utilities.

A built-in assistant answers questions in plain English and can run the steps for you, explaining each one. Before anything risky, the app warns you what could go wrong. Every button also shows the real command it ran, so the terminal slowly starts to make sense.

It adapts to the computer it's on and works on most Linux systems, including Arch, Ubuntu, Fedora and openSUSE, with KDE Plasma, GNOME and other desktops.
