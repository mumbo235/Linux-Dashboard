# Core Features

Linux Dashboard replaces dozens of fragmented commands and desktop apps with unified control panels.

---

## 🔋 Battery & Power Management

- **Precision Tracking**: Battery charge shows clean 1-decimal precision with real-time discharge / charge detection.
- **Smart Color States**:
  - 🟢 Normal: Fully charged or discharging safely above 60%.
  - 🟡 Warning: Discharging below 60%.
  - 🔴 Low: Discharging below 30%.
- **Power Profiles**: Toggle between Performance, Balanced, and Power Saver profiles via `power-profiles-daemon`.
- **Fan Control**: Supported for Apple Silicon (Asahi), T2 Macs, and Intel Macbooks.

---

## ⚡ Global Search Palette (<kbd>Ctrl</kbd> + <kbd>K</kbd>)

Press <kbd>Ctrl</kbd> + <kbd>K</kbd> anywhere to search:
- **Desktop Actions**: Take screenshots, lock screen, empty trash, toggle night light.
- **Settings**: Quick jump to appearance, zoom, fonts, audio devices.
- **Installed Apps**: Open apps directly or check system processes.
- **Guides & Guided Fixes**: Step-by-step diagnostic workflows.

---

## 📜 System Drawer & Terminal Activity (<kbd>Ctrl</kbd> + <kbd>`</kbd>)

Press <kbd>Ctrl</kbd> + <kbd>`</kbd> to slide out the activity drawer:
- Live streaming output of all commands run by the dashboard or assistant.
- Copy output, stop running background jobs, or ask the AI assistant to explain why a command failed.

---

## 🖥️ Supported Desktop Environments

| Desktop | Native Features |
|---|---|
| **KDE Plasma 6 & 5** | Themes, accent colors, night color, window rules, displays, panels, virtual desktops |
| **GNOME 40+** | Dark mode, accent colors, night light, extensions, dock, wallpapers, idle timeouts |
| **Cinnamon / XFCE / MATE** | System services, sound, networking, disks, sensors, power management |
